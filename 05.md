# JavaScript – Array.isArray

Array.isArray permite comprobar de forma fiable si un valor es un array

Ejemplo:

    Array.isArray([1, 2, 3]); // true
    Array.isArray("hola");    // false
    Array.isArray({});        // false

Usar typeof no sirve para distinguir correctamente un array:

    typeof [1, 2, 3]; // "object"

Por este motivo, cuando una función necesita comprobar que recibe un array, Array.isArray suele ser la opción adecuada.
