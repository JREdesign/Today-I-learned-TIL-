# JavaScript – Optional chaining (?.)

Optional chaining ayuda a acceder a propiedades anidadas sin lanzar error cuando algo es null o undefined.

Ejemplo:

    const city = user?.address?.city;

Si en algún punto user o address no existe, la expresión devuelve undefined en lugar de lanzar una excepción

# JavaScript – Nullish coalescing (??)

El operador ?? permite usar un valor por defecto solo cuando el valor es null o undefined, a diferencia de || que trata como falsy valores como 0, "" o false.

Ejemplo:

    const a = 0;
    const conOr = a || 10;      // 10
    const conNullish = a ?? 10; // 0

# JavaScript – Closures

Un closure ocurre cuando una función “recuerda” el entorno en el que fue creada, incluso si se ejecuta más tarde fuera de ese ámbito.

Ejemplo típico:

    function createCounter() {
      let count = 0;
      return function () {
        count += 1;
        return count;
      };
    }

Esto se usa mucho en callbacks, factories y para mantener estado.

# JavaScript – AbortController
AbortController permite cancelar operaciones asíncronas como fetch cuando dejan de ser necesarias (por ejemplo al cambiar de página).
