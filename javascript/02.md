# JavaScript – Optional chaining (?.)

Optional chaining ayuda a acceder a propiedades anidadas sin lanzar error cuando algo es null o undefined.

Ejemplo:

    const city = user?.address?.city;

Si en algún punto user o address no existe, la expresión devuelve undefined en lugar de lanzar una excepción

---

# JavaScript – Nullish coalescing (??)

El operador ?? permite usar un valor por defecto solo cuando el valor es null o undefined, a diferencia de || que trata como falsy valores como 0, "" o false.
