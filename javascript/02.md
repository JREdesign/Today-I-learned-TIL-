# JavaScript – Optional chaining (?.)

Optional chaining ayuda a acceder a propiedades anidadas sin lanzar error cuando algo es null o undefined.

Ejemplo:

    const city = user?.address?.city;

Si en algún punto user o address no existe, la expresión devuelve undefined en lugar de lanzar una excepción

# JavaScript – Nullish coalescing (??)

El operador ?? permite usar un valor por defecto solo cuando el valor es null o undefined, a diferencia de || que trata como falsy valores como 0, "" o false.

Ejemplo:

    const a = 0;
    const conOr = a || 10;      // 10
    const conNullish = a ?? 10; // 0

# JavaScript – Closures

Un closure ocurre cuando una función “recuerda” el entorno en el que fue creada, incluso si se ejecuta más tarde fuera de ese ámbito.

Ejemplo típico:

    function createCounter() {
      let count = 0;
      return function () {
        count += 1;
        return count;
      };
    }

Esto se usa mucho en callbacks, factories y para mantener estado.

# JavaScript – AbortController
AbortController permite cancelar operaciones asíncronas como fetch cuando dejan de ser necesarias (por ejemplo al cambiar de página).

Ejemplo:

    const controller = new AbortController();

    fetch("/api/data", { signal: controller.signal })
      .catch(err => {
        if (err.name === "AbortError") return;
        throw err;
      });

    controller.abort();

Evita estados inconsistentes y trabajo innecesario en la aplicación

# JavaScript – structuredClone

structuredClone permite realizar una copia profunda (deep copy) de objetos y arrays, creando una nueva estructura completamente independiente del original, incluso en niveles anidados.
A diferencia de JSON.parse(JSON.stringify(obj)), no pierde tipos especiales ni convierte datos automáticamente. Conserva correctamente tipos como Date, Map, Set, RegExp, Error, ArrayBuffer, entre otros, y además soporta referencias circulares.
Ejemplo:
JavaScript
Copiar código
const original = { a: 1, nested: { b: 2 } };
const copy = structuredClone(original);

copy.nested.b = 99;

original.nested.b; // 2
Es la forma moderna y más segura de clonar datos complejos en JavaScript.

# JavaScript – parseInt y radix

parseInt convierte un string a número entero, pero es buena práctica indicar la base (radix) para evitar interpretaciones raras.

Ejemplo recomendado:

    parseInt("10", 10)
