# JavaScript – Optional chaining (?.)

Optional chaining ayuda a acceder a propiedades anidadas sin lanzar error cuando algo es null o undefined.

Ejemplo:

    const city = user?.address?.city;

Si en algún punto user o address no existe, la expresión devuelve undefined en lugar de lanzar una excepción

# JavaScript – Nullish coalescing (??)

El operador ?? permite usar un valor por defecto solo cuando el valor es null o undefined, a diferencia de || que trata como falsy valores como 0, "" o false.

Ejemplo:

    const a = 0;
    const conOr = a || 10;      // 10
    const conNullish = a ?? 10; // 0

# JavaScript – Closures

Un closure ocurre cuando una función “recuerda” el entorno en el que fue creada, incluso si se ejecuta más tarde fuera de ese ámbito.

Ejemplo típico:

    function createCounter() {
      let count = 0;
      return function () {
        count += 1;
        return count;
      };
    }

Esto se usa mucho en callbacks, factories y para mantener estado.

# JavaScript – AbortController
AbortController permite cancelar operaciones asíncronas como fetch cuando dejan de ser necesarias (por ejemplo al cambiar de página).

Ejemplo:

    const controller = new AbortController();

    fetch("/api/data", { signal: controller.signal })
      .catch(err => {
        if (err.name === "AbortError") return;
        throw err;
      });

    controller.abort();

Evita estados inconsistentes y trabajo innecesario en la aplicación

# JavaScript – structuredClone

structuredClone permite realizar una copia profunda (deep copy) de objetos y arrays, creando una nueva estructura completamente independiente del original, incluso en niveles anidados.
A diferencia de JSON.parse(JSON.stringify(obj)), no pierde tipos especiales ni convierte datos automáticamente. Conserva correctamente tipos como Date, Map, Set, RegExp, Error, ArrayBuffer, entre otros, y además soporta referencias circulares.
Ejemplo:
JavaScript
Copiar código
const original = { a: 1, nested: { b: 2 } };
const copy = structuredClone(original);

copy.nested.b = 99;

original.nested.b; // 2
Es la forma moderna y más segura de clonar datos complejos en JavaScript.

# JavaScript – parseInt y radix

parseInt convierte un string a número entero, pero es buena práctica indicar la base (radix) para evitar interpretaciones raras.

Ejemplo recomendado:

    parseInt("10", 10)

Si no se indica radix, puede haber casos confusos con strings que parecen octales en algunos contextos antiguos, y además el código queda menos explícito.

# JavaScript – Number.isNaN vs isNaN

isNaN realiza coerción de tipos, lo que puede dar resultados raros.

Ejemplo:

    isNaN("hola") // true (porque intenta convertir)

En cambio, Number.isNaN solo devuelve true si el valor es realmente NaN:

    Number.isNaN("hola") // false
    Number.isNaN(NaN)    // true

Por eso, en la práctica suele preferirse Number.isNaN para comprobar NaN.

# JavaScript – Array.at() e índices negativos

`Array.at()` es un método moderno de JavaScript que permite acceder a elementos de un array mediante índices positivos y negativos. Su principal ventaja es que simplifica el acceso a posiciones relativas desde el final del array, mejorando la legibilidad del código.

Cuando se utilizan índices negativos, el conteo comienza desde el final del array: `-1` representa el último elemento, `-2` el penúltimo, y así sucesivamente. Esto evita tener que calcular manualmente la longitud del array.

Ejemplo:

```
const arr = [10, 20, 30];
arr.at(0)   // 10
arr.at(-1)  // 30
arr.at(-2)  // 20
```

Además, si el índice está fuera del rango válido, `Array.at()` devuelve `undefined` en lugar de lanzar un error, lo que lo hace seguro de usar en muchos casos.

Es una alternativa más clara y expresiva a expresiones como `arr[arr.length - 1]`, especialmente cuando se trabaja frecuentemente con los últimos elementos de un array.
