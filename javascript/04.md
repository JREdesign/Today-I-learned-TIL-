# JavaScript – Array.from

Array.from permite crear arrays a partir de objetos iterables o parecidos a arrays.

Ejemplo con string:

    Array.from("hola") // ["h", "o", "l", "a"]

Ejemplo con longitud:

    Array.from({ length: 3 }, (_, i) => i) // [0, 1, 2]


Es útil para convertir NodeList, strings o crear arrays rápidos con una longitud concreta.

# JavaScript – Object.freeze

`Object.freeze` evita que se añadan, eliminen o modifiquen las propiedades directas de un objeto.

Ejemplo:

    const config = Object.freeze({ theme: "dark" });

    config.theme = "light"; // No cambia
    config.language = "es"; // No se añade
    delete config.theme;    // No se elimina

En modo estricto, intentar modificar un objeto congelado puede lanzar un error. Fuera del modo estricto, normalmente la operación simplemente se ignora.

También podemos comprobar si un objeto está congelado con:

    Object.isFrozen(config); // true

Importante: `Object.freeze` es superficial. Si el objeto contiene propiedades anidadas, esos objetos internos no quedan congelados automáticamente.

    const settings = Object.freeze({
        user: {
            name: "Jorge"
        }
    });
    
    settings.user.name = "Carlos"; // Sí se modifica

Para congelar completamente un objeto con varios niveles sería necesario aplicar `Object.freeze` también a sus propiedades internas.

# JavaScript – Array.some y Array.every

some y every permiten comprobar condiciones sobre los elementos de un array.

some devuelve true cuando al menos un elemento cumple la condición:

    const numbers = [1, 3, 6];

    numbers.some(number => number % 2 === 0); // true

every devuelve true únicamente cuando todos los elementos cumplen la condición:

    numbers.every(number => number > 0); // true

# JavaScript – URLSearchParams

URLSearchParams facilita la lectura y creación de parámetros de consulta en una URL.


Ambos métodos dejan de recorrer el array en cuanto ya conocen el resultado, por lo que son más expresivos que crear un array nuevo solo para hacer una comprobación.

Ejemplo para leer parámetros:

    const params = new URLSearchParams("?page=2&search=css");

    params.get("page");   // "2"
    params.get("search"); // "css"
    

También permite crear una cadena de consulta:

    const params = new URLSearchParams({
      page: "1",
      category: "javascript"
    });

    params.toString(); // "page=1&category=javascript"    

Es más cómodo y seguro que construir manualmente los parámetros concatenando strings.

# JavaScript – Array.flatMap

flatMap combina una operación map con un aplanado de un nivel.

Ejemplo:

    const sentences = ["hola mundo", "aprendo JavaScript"];

    const words = sentences.flatMap(
      sentence => sentence.split(" ")
    );

    // ["hola", "mundo", "aprendo", "JavaScript"]

También puede utilizarse para transformar un elemento en varios o eliminarlo devolviendo un array vacío:

    const numbers = [1, 2, 3, 4];

    numbers.flatMap(number =>
      number % 2 === 0 ? [number] : []
    );

    // [2, 4]

Es útil cuando map produciría un array de arrays y después sería necesario aplicar flat.

# JavaScript – Object.fromEntries

Object.fromEntries permite crear un objeto a partir de una colección de pares formados por clave y valor.

Ejemplo:

    const entries = [
      ["name", "Jorge"],
      ["role", "developer"]
    ];
    
    const user = Object.fromEntries(entries);

    // {
    //   name: "Jorge",
    //   role: "developer"
    // }

Es la operación inversa de Object.entries y resulta útil después de filtrar o transformar las propiedades de un objeto.

Ejemplo:

    const settings = {
      theme: "dark",
      debug: false
    };

    const enabledSettings = Object.fromEntries(
      Object.entries(settings).filter(([, value]) => Boolean(value))
    );

    // { theme: "dark" }

# JavaScript – Promise.all
    
Promise.all permite esperar a que varias promesas se resuelvan.

Ejemplo:

    const [user, posts] = await Promise.all([
      fetch("/api/user").then(response => response.json()),
      fetch("/api/posts").then(response => response.json())
    ]);

Las operaciones comienzan sin esperar a que termine la anterior, lo que puede reducir el tiempo total cuando son independientes.

El array de resultados mantiene el mismo orden que las promesas originales, aunque terminen en momentos diferentes.

Es importante recordar que Promise.all rechaza en cuanto una de las promesas falla


    await Promise.all([
      Promise.resolve("correcto"),
      Promise.reject(new Error("fallo"))
    ]);

Para casos donde quieres conocer el resultado de todas las operaciones aunque alguna falle, existe Promise.allSettled.
