# JavaScript – Object.keys, Object.values y Object.entries

Estas utilidades permiten recorrer objetos de forma más cómoda.

Ejemplo:

    const user = { name: "Jorge", role: "admin" };

    Object.keys(user)    // ["name", "role"]
    Object.values(user)  // ["Jorge", "admin"]
    Object.entries(user) // [["name", "Jorge"], ["role", "admin"]]

Son especialmente útiles para iterar, transformar objetos o construir interfaces dinámicamente.

# JavaScript – includes en strings y arrays

includes permite comprobar si un valor aparece dentro de un string o de un array.

En strings:

    "hola mundo".includes("mundo") // true
    
En arrays:

    [1, 2, 3].includes(2) // true

Es más legible que usar indexOf cuando solo necesitas saber si existe o no.

# JavaScript – Math.max con spread

Math.max devuelve el mayor de varios números, pero si tienes un array necesitas expandirlo con spread.

Ejemplo:

    const numbers = [1, 5, 3];
    Math.max(...numbers) // 5

Hay que tener cuidado con arrays muy grandes, porque expandir demasiados elementos puede causar problemas de rendimiento o límites de argumentos.

# JavaScript – Optional catch binding

En JavaScript no siempre necesitas declarar el parámetro de error en un bloque catch.

Ejemplo:

    try {
      JSON.parse("mal");
    } catch {
      console.log("JSON inválido");
    }

Esto es útil cuando no vas a usar el objeto error y solo quieres manejar el fallo de forma genérica.

# JavaScript – encodeURIComponent

encodeURIComponent permite codificar texto para usarlo de forma segura dentro de una URL, por ejemplo en query params.

Ejemplo:

    const search = "camiseta blanca";
        const url = "/buscar?q=" + encodeURIComponent(search);

Resultado:

    /buscar?q=camiseta%20blanca

Es importante cuando el texto contiene espacios, acentos, símbolos o caracteres especiales.
