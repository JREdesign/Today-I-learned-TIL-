# JavaScript – Array.findIndex

findIndex devuelve la posición del primer elemento de un array que cumple una condición.

Ejemplo:

    const users = [
      { id: 10, name: "Ana" },
      { id: 20, name: "Carlos" }
    ];

    const index = users.findIndex(
      user => user.id === 20
    );

    // 1

Si ningún elemento cumple la condición, devuelve -1.

Esto resulta útil cuando no solo necesitas encontrar un elemento, sino conocer su posición para modificarlo, eliminarlo o trabajar con los elementos cercanos.

## Diferencia con find

`find()` devuelve el elemento encontrado, mientras que `findIndex()` devuelve su posición.

    users.find(user => user.id === 20);
    // { id: 20, name: "Carlos" }

    users.findIndex(user => user.id === 20);
    // 1

## Actualizar un elemento a partir de su índice

Conviene comprobar que el resultado no sea `-1` antes de utilizarlo como índice.

    const position = users.findIndex(user => user.id === 20);

    if (position !== -1) {
      users[position] = { ...users[position], name: "Carla" };
    }

En este ejemplo se sustituye el objeto de la posición encontrada por otro con el nombre actualizado.
