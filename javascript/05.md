# JavaScript – Array.findIndex

findIndex devuelve la posición del primer elemento de un array que cumple una condición.

Ejemplo:

    const users = [
      { id: 10, name: "Ana" },
      { id: 20, name: "Carlos" }
    ];

    const index = users.findIndex(
      user => user.id === 20
    );

    // 1

Si ningún elemento cumple la condición, devuelve -1.

Esto resulta útil cuando no solo necesitas encontrar un elemento, sino conocer su posición para modificarlo, eliminarlo o trabajar con los elementos cercanos.

# JavaScript – String.replaceAll

replaceAll permite sustituir todas las apariciones de un texto dentro de un string.

Ejemplo:

    const text = "rojo, rojo y rojo";

    const result = text.replaceAll(
      "rojo",
      "azul"
    );

    // "azul, azul y azul"

Con replace tradicional usando un string solo se sustituye la primera aparición:

    "hola hola".replace("hola", "adiós");

    // "adiós hola"

## Coincidencias exactas y cadenas originales

Cuando buscamos un texto literal, `replaceAll()` distingue entre mayúsculas y minúsculas. Además, devuelve una cadena nueva: no modifica la original.

```js
const original = "Sol, sol y SOL";
const actualizado = original.replaceAll("sol", "luna");

console.log(actualizado); // "Sol, luna y SOL"
console.log(original);    // "Sol, sol y SOL"
```

## Sustituir sin distinguir mayúsculas y minúsculas

También se puede utilizar una expresión regular con las banderas `g` (búsqueda global) e `i` (sin distinguir mayúsculas de minúsculas).

```js
const texto = "Sol, sol y SOL";
const resultado = texto.replaceAll(/sol/gi, "luna");

console.log(resultado); // "luna, luna y luna"
```

**Importante:** si el primer argumento de `replaceAll()` es una expresión regular, debe incluir la bandera `g`; de lo contrario, JavaScript lanza un `TypeError`. Con texto literal, la bandera no es necesaria.

## Sustituciones dinámicas con una función

El segundo argumento de `replaceAll()` también puede ser una función. Resulta útil cuando el texto de reemplazo debe calcularse para cada coincidencia.

```js
const texto = "Producto 2 y producto 5";
const resultado = texto.replaceAll(/\d+/g, (numero) => String(Number(numero) * 2));

console.log(resultado); // "Producto 4 y producto 10"
```

La función recibe la coincidencia y devuelve el texto que se insertará en su lugar.
