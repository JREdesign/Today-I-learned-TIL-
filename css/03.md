# CSS – scrollbar-gutter


`scrollbar-gutter` permite reservar espacio para la barra de scroll y evitar pequeños saltos de layout cuando aparece o desaparece.

Esto ayuda a que el contenido no cambie ligeramente de posición, sobre todo en ejes horizontales, cuando un contenedor pasa de no necesitar scroll a mostrarlo.

Ejemplo:

    .panel {
      overflow: auto;
      scrollbar-gutter: stable;
    }

Con `stable`, el navegador mantiene ese espacio reservado incluso cuando la barra todavía no es visible.
