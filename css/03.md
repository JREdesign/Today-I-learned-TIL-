# CSS – scrollbar-gutter


`scrollbar-gutter` permite reservar espacio para la barra de scroll y evitar pequeños saltos de layout cuando aparece o desaparece.

Esto ayuda a que el contenido no cambie ligeramente de posición, sobre todo en ejes horizontales, cuando un contenedor pasa de no necesitar scroll a mostrarlo.

Ejemplo:

    .panel {
      overflow: auto;
      scrollbar-gutter: stable;
    }

Con `stable`, el navegador mantiene ese espacio reservado incluso cuando la barra todavía no es visible.

Esto puede ser útil en contenedores con contenido dinámico, donde la aparición de la barra desplaza el contenido horizontalmente. También mejora la estabilidad visual en interfaces con paneles, modales, tablas o bloques que cambian de tamaño según su contenido.

No siempre será necesario, pero en componentes donde pequeños movimientos del layout resultan molestos, puede ser una propiedad bastante práctica.

# CSS – pointer-events

pointer-events permite controlar si un elemento puede recibir clics o interacción del puntero.

Ejemplo:

    .overlay {
      pointer-events: none;
    }

Esto es útil cuando tienes capas visuales por encima de otros elementos pero no quieres que bloqueen la interacción.

También puede activarse solo en hijos concretos si el contenedor general no debe capturar eventos.

# CSS – accent-color

accent-color permite personalizar el color de controles nativos del navegador como checkboxes, radios o barras de progreso.

Ejemplo:

    input[type="checkbox"] {
      accent-color: rebeccapurple;
    }
    
Es una forma sencilla de dar coherencia visual a formularios sin tener que rehacer completamente los controles nativos.

---

# CSS – user-select

user-select controla si el usuario puede seleccionar texto dentro de un elemento.


Ejemplo:

    .button {
      user-select: none;
    }

Esto puede ser útil en botones, controles personalizados o elementos interactivos donde seleccionar texto accidentalmente empeora la experiencia.

También se puede permitir selección explícitamente con:

    .content {
      user-select: text;
    }

# CSS – text-wrap: balance

text-wrap: balance intenta equilibrar las líneas de texto para que títulos y encabezados tengan una composición visual más agradable.

Ejemplo:

    h1 {
      text-wrap: balance;
    }

Es especialmente útil en headings largos donde una última línea muy corta puede quedar visualmente extraña.

---

# CSS – scroll-margin-top

scroll-margin-top permite añadir un margen al hacer scroll hacia un elemento, por ejemplo cuando navegas a un ancla con un header sticky.

Ejemplo:

    section {
      scroll-margin-top: 80px;
    }
    
Esto evita que el título de una sección se quede escondida debajo de una barra fija o sticky.

# CSS – caret-color

caret-color permite cambiar el color del cursor de texto en inputs, textareas o elementos editables.
