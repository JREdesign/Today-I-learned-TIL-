# CSS – resize en textareas

La propiedad resize permite controlar si un elemento puede ser redimensionado por el usuario.

Ejemplo:

    textarea {
      resize: vertical;
    }

Valores comunes:

- none: no permite redimensionar
- vertical: solo permite redimensionar en vertical
- horizontal: solo permite redimensionar en horizontal
- both: permite redimensionar en ambas direcciones

En textareas suele ser útil permitir resize vertical para mejorar la experiencia sin romper el layout horizontal.

# CSS – white-space

white-space controla cómo se manejan los espacios y saltos de línea dentro de un elemento.

Ejemplo:

    .text {
      white-space: nowrap;
    }
    
Valores comunes:

- normal: comportamiento estándar
- nowrap: evita saltos de línea
- pre: respeta espacios y saltos de línea
- pre-wrap: respeta saltos, pero permite envolver texto

Es útil en etiquetas, botones, código o textos que no deben romperse.
