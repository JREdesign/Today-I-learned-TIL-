# CSS – resize en textareas

La propiedad resize permite controlar si un elemento puede ser redimensionado por el usuario.

Ejemplo:

    textarea {
      resize: vertical;
    }

Valores comunes:

- none: no permite redimensionar
- vertical: solo permite redimensionar en vertical
- horizontal: solo permite redimensionar en horizontal
- both: permite redimensionar en ambas direcciones

En textareas suele ser útil permitir resize vertical para mejorar la experiencia sin romper el layout horizontal.

# CSS – white-space

white-space controla cómo se manejan los espacios y saltos de línea dentro de un elemento.

Ejemplo:

    .text {
      white-space: nowrap;
    }
    
Valores comunes:

- normal: comportamiento estándar
- nowrap: evita saltos de línea
- pre: respeta espacios y saltos de línea
- pre-wrap: respeta saltos, pero permite envolver texto

Es útil en etiquetas, botones, código o textos que no deben romperse.

# CSS – overflow-wrap

overflow-wrap controla si el navegador puede dividir una palabra demasiado larga para evitar que sobresalga de su contenedor.

Ejemplo:

    .content {
      overflow-wrap: break-word;
    }

Esto resulta útil con URLs, identificadores o textos generados por usuarios que pueden contener cadenas largas sin espacios.

También existe el valor anywhere, que permite romper la palabra en cualquier punto cuando sea necesario.

# CSS – currentColor

currentColor representa el valor actual de la propiedad color de un elemento.

Puede reutilizarse en bordes, fondos, sombras o iconos para mantener una relación automática con el color del texto.

Ejemplo:

    .button {
      color: rebeccapurple;
      border: 2px solid currentColor;
    }

Si cambia la propiedad color del botón, el borde también cambia sin necesidad de repetir el mismo valor.

Esto resulta especialmente práctico en componentes con diferentes estados o variantes de color.

# CSS – line-clamp

line-clamp permite limitar el número de líneas visibles de un texto y mostrar puntos suspensivos cuando el contenido es demasiado largo.

Ejemplo:

    .description {
      display: -webkit-box;
      -webkit-box-orient: vertical;
      -webkit-line-clamp: 3;
      overflow: hidden;
    }

Este patrón resulta útil en tarjetas, listados y componentes donde todas las descripciones deben ocupar una altura similar.

# CSS – isolation

La propiedad isolation permite crear explícitamente un nuevo contexto de apilamiento.

Ejemplo:

Conviene recordar que el contenido completo sigue existiendo, aunque visualmente quede recortado.

    .component {
      isolation: isolate;
    }

Esto puede ser útil en componentes que contienen elementos con z-index, ya que evita que su orden de apilamiento interfiera con elementos externos.

También ayuda a controlar overlays, badges o decoraciones posicionadas sin depender de valores de z-index excesivamente altos.

# CSS – overscroll-behavior

overscroll-behavior permite controlar qué ocurre cuando el usuario llega al límite de desplazamiento de un contenedor.

Ejemplo:

    .modal-content {
      overflow-y: auto;
      overscroll-behavior: contain;
    }

El valor contain evita que, al llegar al final del scroll del modal, el desplazamiento continúe afectando a la página que se encuentra detrás.

Algunos valores habituales son:

- auto: mantiene el comportamiento normal.
- contain: evita que el scroll se propague a otros contenedores.
- none: evita la propagación y otros efectos asociados al límite del scroll.

# CSS – color-scheme

La propiedad color-scheme indica al navegador qué esquemas de color admite una página o un componente.

Ejemplo:

    :root {
      color-scheme: light dark;
    }

Esto permite que ciertos elementos nativos, como formularios, barras de desplazamiento y controles del navegador, se adapten automáticamente al modo claro u oscuro del sistema.

También puede aplicarse a un componente concreto:

    .dark-panel {
      color-scheme: dark;
    }

No sustituye la definición de colores propios, pero ayuda a que los controles nativos encajen mejor con la apariencia de la interfaz.
