# CSS – inset

La propiedad inset es una forma abreviada de definir top, right, bottom y left en elementos posicionados.

En lugar de escribir:

    .overlay {
      position: absolute;
      top: 0;
      right: 0;
      bottom: 0;
      left: 0;
    }
    
Se puede escribir:

    .overlay {
      position: absolute;
      inset: 0;
    }

También admite varios valores, de forma parecida a margin o padding:

    .element {
      inset: 10px 20px;
    }

Esto resulta especialmente útil para overlays, fondos y elementos posicionados que deben ocupar todo su contenedor.

# CSS – min(), max() y clamp()

CSS dispone de funciones que permiten definir valores adaptables sin necesitar siempre media queries.

min() utiliza el menor de los valores indicados:

    width: min(100%, 800px);

max() utiliza el mayor:

    padding: max(16px, 2vw);

clamp() permite definir un mínimo, un valor adaptable y un máximo:

    font-size: clamp(1rem, 2vw, 2rem);

Esto resulta especialmente útil para tamaños de fuente, espacios y contenedores responsive.

# CSS – :focus-visible

La pseudo-clase :focus-visible permite aplicar estilos de foco principalmente cuando el navegador considera que el usuario necesita una indicación visual, por ejemplo al navegar con teclado.

Ejemplo:

    button:focus-visible {
      outline: 3px solid currentColor;
      outline-offset: 3px;
    }
