# CSS – inset

La propiedad inset es una forma abreviada de definir top, right, bottom y left en elementos posicionados.

En lugar de escribir:

    .overlay {
      position: absolute;
      top: 0;
      right: 0;
      bottom: 0;
      left: 0;
    }
    
Se puede escribir:

    .overlay {
      position: absolute;
      inset: 0;
    }
