# CSS – gap en Flexbox

La propiedad gap no es exclusiva de CSS Grid; también se puede usar con Flexbox y permite separar elementos de forma limpia, sin tener que aplicar márgenes manuales a cada hijo.

Ejemplo:

    .row {
      display: flex;
      gap: 12px;
    }
Esto suele ser más mantenible que usar margin-right o trucos con :last-child.

# CSS – Stacking context y z-index

Cuando un z-index parece “no funcionar”, a menudo el motivo es el stacking context. Ciertos estilos como transform u opacity pueden crear un nuevo contexto de apilamiento y cambiar cómo se ordenan elementos.

Consejo práctico: si un overlay queda detrás de algo, revisa si algún padre tiene transform, opacity < 1 o un z-index que esté creando un stacking context.

# CSS – Outline vs border para depurar

Cuando depuras un layout, outline es útil porque no ocupa espacio en el flujo, a diferencia de border, que puede alterar el tamaño y mover elementos.

Usar outline temporalmente en elementos ayuda a ver cajas sin cambiar el layout.

# CSS - Margin collapse

El margin collapse (colapso de márgenes) ocurre cuando márgenes verticales de elementos de bloque se combinan y el resultado no es la suma de ambos, sino el mayor de los dos. Esto sorprende cuando el margen superior del primer hijo parece “salirse” del contenedor.

Formas comunes de evitarlo:

- Añadir padding al contenedor.
- Forzar un nuevo contexto de formato con overflow.

---

Ejemplos:

    .container {
      padding-top: 1px;
    }

    .container {
      overflow: auto;
    }

# CSS – aspect-ratio y medios responsive

aspect-ratio
La propiedad aspect-ratio permite definir una relación de aspecto para un elemento, lo que ayuda a reservar espacio antes de que carguen imágenes o iframes y evita saltos de layout.

Ejemplo:

    .card-media {
      aspect-ratio: 16 / 9;
    }

Esto es útil para contenedores de vídeo, thumbnails o banners.


## object-fit (cuando hay imágenes)

Si el elemento es una imagen o vídeo, object-fit controla cómo se adapta al contenedor:

    img.cover {
      width: 100%;
      height: 100%;
      object-fit: cover;
    }

Combinar aspect-ratio con object-fit suele dar resultados muy sólidos en UI responsive.

# CSS – object-fit

object-fit controla cómo una imagen o vídeo se adapta a su contenedor cuando tiene dimensiones fijas.

Valores comunes:

- cover: rellena el contenedor recortando
- contain: encaja completo sin recortar

Ejemplo:

    img.cover {
      width: 100%;
      height: 100%;
      object-fit: cover;
    }

# CSS – Container Queries

Las container queries permiten aplicar estilos según el tamaño del contenedor en lugar del viewport.

Ejemplo:

    .card {
      container-type: inline-size;
    }

    @container (min-width: 400px) {
      .card-content {
        display: flex;
      }
    }
