# CSS – gap en Flexbox

La propiedad gap no es exclusiva de CSS Grid; también se puede usar con Flexbox y permite separar elementos de forma limpia, sin tener que aplicar márgenes manuales a cada hijo.

Ejemplo:

    .row {
      display: flex;
      gap: 12px;
    }
Esto suele ser más mantenible que usar margin-right o trucos con :last-child.

# CSS – Stacking context y z-index

Cuando un z-index parece “no funcionar”, a menudo el motivo es el stacking context. Ciertos estilos como transform u opacity pueden crear un nuevo contexto de apilamiento y cambiar cómo se ordenan elementos.

Consejo práctico: si un overlay queda detrás de algo, revisa si algún padre tiene transform, opacity < 1 o un z-index que esté creando un stacking context.

# CSS – Outline vs border para depurar

Cuando depuras un layout, outline es útil porque no ocupa espacio en el flujo, a diferencia de border, que puede alterar el tamaño y mover elementos.

Usar outline temporalmente en elementos ayuda a ver cajas sin cambiar el layout.
