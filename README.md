# Today-I-learned-TIL-
Este repositorio reúne pequeñas notas diarias sobre conceptos, técnicas y descubrimientos que voy aprendiendo en mi día a día como desarrollador web. La idea es mantener un registro sencillo, organizado y fácil de consultar que me permita recordar soluciones, aclarar conceptos y documentar trucos útiles relacionados con JavaScript, HTML y CSS.
