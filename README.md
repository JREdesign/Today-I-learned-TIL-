# 🧠 Today-I-learned (TIL)

Este repositorio reúne una colección creciente de pequeñas notas técnicas que voy recopilando día a día mientras aprendo, repaso o descubro conceptos relacionados con el desarrollo web. La finalidad principal de este TIL es disponer de un espacio organizado y fácil de consultar donde pueda documentar de manera sencilla todo aquello que voy incorporando a mi conocimiento, especialmente dentro del ámbito de **JavaScript**, **HTML** y **CSS**, que son las tecnologías que utilizo con más frecuencia.

Cada nota está guardada como un archivo en formato Markdown dentro de una categoría concreta. No se trata de artículos extensos ni de ejercicios completos, sino de apuntes breves que registran ideas importantes, trucos prácticos, fragmentos de código explicativos, detalles semánticos o cualquier otro concepto que quiera recordar en el futuro. Este enfoque permite mantener una estructura ligera, clara y flexible, que puede crecer de manera natural conforme vaya aprendiendo nuevas cosas.

El objetivo final de este repositorio es fomentar un hábito de aprendizaje continuo mediante pequeñas entradas, evitando la presión de tener que escribir documentos largos, y creando así una referencia personal que evolucione al mismo ritmo que mis propias habilidades. Con el tiempo, este TIL se convierte en una especie de cuaderno digital técnico, siempre disponible para consulta y ampliación.

---

## 📂 Estructura del repositorio

El contenido está organizado por carpetas según la temática:

- **javascript/** – Conceptos del lenguaje, funciones útiles, patrones comunes, buenas prácticas, diferencias entre estructuras y cualquier idea relevante relacionada con JS.
- **css/** – Trucos visuales, propiedades interesantes, comportamientos poco intuitivos, notas sobre layout, flexbox, grid y todo aquello relacionado con la apariencia.
- **html/** – Semántica, accesibilidad, etiquetas específicas, propiedades relevantes del DOM y pequeñas aclaraciones sobre estructura de documentos.

Cada carpeta contiene varios archivos `.md`, cada uno representando un aprendizaje diferente.

## ✍️ ¿Qué considero un TIL?

Un TIL es una nota corta que explica algo que aprendí, entendí mejor o descubrí en un momento concreto.  
Puede ser:

- Una función que no conocía o cuyo comportamiento he comprendido mejor.  
- Una propiedad de CSS que me ha resultado útil o sorprendente.  
- Un detalle semántico de HTML que aporta claridad al documento.  
- Un patrón de código cuyo propósito entiendo de forma más profunda.  
- Un error que resolví y cuyo proceso quiero recordar.  

No tiene por qué ser algo complejo; la clave es que sea **útil** para mí en el futuro.
---

## 📜 Filosofía del repositorio

- Mantener las entradas cortas, claras y enfocadas.  
- Priorizar la constancia sobre la perfección o la amplitud.  
- Usar ejemplos mínimos para ilustrar los conceptos.  
- Evitar convertir este TIL en un repositorio de proyectos; es una libreta técnica.  
- Dejar que el repositorio crezca poco a poco, sin presión y sin reglas estrictas.
