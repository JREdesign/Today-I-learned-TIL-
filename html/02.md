9# HTML – target="_blank" y rel="noopener"

Cuando abres enlaces en una nueva pestaña con target="_blank", es buena práctica añadir rel="noopener" para evitar que la página abierta pueda acceder a window.opener.

Ejemplo:

    <a href="https://example.com" target="_blank" rel="noopener">Enlace</a>

# HTML – type en &lt;button&gt; dentro de formularios

Dentro de un &lt;form&gt;, un &lt;button&gt; sin type puede comportarse como submit y provocar envíos accidentales.

Recomendación: ser explícito.

    <button type="submit">Guardar</button>
    <button type="button">Cancelar</button>

---

# HTML – srcset

srcset permite ofrecer distintas resoluciones de imagen para que el navegador elija la más adecuada.

Ejemplo:

    <img
      src="foto-800.jpg"
      srcset="foto-400.jpg 400w, foto-800.jpg 800w, foto-1200.jpg 1200w"
      alt="..."
    />

Mejora el rendimiento en dispositivos móviles.

---
# HTML – loading lazy

El atributo loading permite diferir la carga de imágenes fuera del viewport.

Ejemplo:

    <img src="foto.jpg" loading="lazy" alt="..." />

Reduce consumo de red y mejora el tiempo de carga inicial.

---

# HTML – inputmode en móviles

inputmode sugiere al teclado del móvil qué tipo de entrada es esperada, mejorando la experiencia de usuario sin cambiar el tipo real del input.

Ejemplo:

    <input inputmode="numeric" />

Otros valores útiles son email, decimal o tel.

Esto es especialmente útil cuando quieres un input de texto pero con teclado numérico.

---

# HTML – autocomplete en formularios

autocomplete ayuda al navegador a completar datos del usuario (nombre, email, dirección) y mejora la experiencia en formularios.

Ejemplos:

    <input name="email" autocomplete="email" />
    <input name="name" autocomplete="name" />

También existe:

    autocomplete="off"
    
pero conviene usarlo con cuidado, porque a veces empeora la usabilidad si se desactiva sin motivo.

---

# HTML – atributo rel en enlaces con target="_blank"

Cuando usas <a target="_blank">, la nueva pestaña puede acceder al objeto window.opener y potencialmente redirigir la página original (riesgo de seguridad conocido como tabnabbing).

Recomendación: añadir rel="noopener noreferrer".

<a href ="https://ejemplo.com"  target="_blank" rel ="noopener noreferrer">Abrir enlace seguro</a>

---
# HTML – &lt;details&gt; y &lt;summary&gt;

details y summary permiten crear un acordeón nativo sin JavaScript.

Ejemplo:

    <details>
      <summary>Más información</summary>
      <p>Contenido expandible</p>
    </details>

Es una forma rápida de contenido colapsable, aunque conviene estilizarlo y comprobar accesibilidad según el caso.

---

# HTML – picture y source

El elemento picture permite servir distintas imágenes según el tamaño de pantalla o el formato soportado por el navegador.

Ejemplo:

    <picture>
      <source srcset="hero.avif" type="image/avif" />
      <source srcset="hero.webp" type="image/webp" />
      <img src="hero.jpg" alt="..." />
    </picture>

Esto ayuda a mejorar rendimiento y compatibilidad, porque el navegador elige la mejor opción disponible.
