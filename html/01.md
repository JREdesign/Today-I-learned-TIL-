## HTML – Notas iniciales

Este archivo recoge varios conceptos y recordatorios básicos sobre HTML que he ido aprendiendo o repasando, organizados en secciones independientes para facilitar su consulta futura.

---

## Diferencia entre &lt;section&gt; y &lt;article&gt;

El elemento &lt;section&gt; se utiliza para agrupar contenido relacionado dentro de una página, mientras que &lt;article&gt; representa una unidad de contenido independiente que podría existir por sí misma, como una entrada de blog, un comentario o una tarjeta de producto.

---

## Para qué sirve el meta viewport

El meta viewport indica al navegador cómo debe adaptar el contenido al ancho real del dispositivo, siendo fundamental para un diseño responsive correcto.

Ejemplo habitual:

    <meta name="viewport" content="width=device-width, initial-scale=1">

---

## Atributos globales en HTML

Existen ciertos atributos que pueden aplicarse a prácticamente cualquier elemento HTML. Algunos de los más comunes son id, class, title, lang, data-*, hidden y tabindex. Estos atributos permiten controlar aspectos de accesibilidad, estilo y comportamiento.

---

## Uso correcto de la etiqueta &lt;label&gt;

La etiqueta &lt;label&gt; se utiliza para describir controles de formulario y debe estar correctamente asociada a su input correspondiente para mejorar la accesibilidad y la experiencia de usuario.

Ejemplo con atributo for:

    <label for="email">Correo electrónico</label>
    <input type="email" id="email">

---

## Uso de la etiqueta &lt;link&gt;

La etiqueta &lt;link&gt; se utiliza para establecer relaciones entre el documento HTML y recursos externos como hojas de estilo, iconos o archivos de manifiesto, y suele colocarse dentro del elemento &lt;head&gt;.

Ejemplo básico:

    <link rel="stylesheet" href="styles.css">
    
---

## HTML – Atributos booleanos

En HTML existen ciertos atributos conocidos como atributos booleanos. Su sola presencia indica que están activados, independientemente del valor que se les asigne.

Algunos ejemplos comunes son disabled, checked, required, readonly o autofocus.

Cuando un atributo booleano está presente, se considera verdadero:

    <input type="checkbox" checked>

También es válido escribirlo sin valor explícito:

    <input type="checkbox" checked>

Si el atributo no está presente, se considera falso.

Comprender este comportamiento evita errores al manipular formularios y al generar HTML dinámicamente desde JavaScript.

---

# Atributos data-* en HTML

Los atributos `data-*` permiten almacenar información personalizada en elementos HTML sin afectar la semántica. Son muy útiles cuando necesitas asociar datos a un elemento para leerlos desde JavaScript o para debugging.
