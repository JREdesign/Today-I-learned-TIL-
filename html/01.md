# Diferencia entre < section > y < article >

Hoy aprendí que, aunque ambos elementos se parecen y a veces se usan indistintamente, tienen propósitos semánticos distintos que ayudan al navegador y a tecnologías de asistencia a entender mejor la estructura del documento.

- **< section >** agrupa contenido que forma parte de una sección temática dentro de la página. No tiene identidad propia fuera del documento y suele llevar un encabezado que describe su propósito.

- **< article >** representa una unidad de contenido independiente que podría existir fuera de la página sin perder sentido, como un post, un comentario, una tarjeta de producto o una entrada de blog.

Comprender esta diferencia ayuda a construir documentos más claros, accesibles y bien estructurados.



# Para qué sirve el meta viewport

Hoy repasé la importancia del meta viewport en páginas web orientadas a dispositivos móviles. Este elemento indica al navegador cómo debe escalar y presentar el contenido en pantallas pequeñas.

```html
<meta name="viewport" content="width=device-width, initial-scale=1">

width=device-width hace que el ancho de la página coincida con el ancho real del dispositivo.

initial-scale=1 establece el nivel de zoom inicial para que la página no aparezca ampliada.

Sin esta etiqueta, el navegador asume un ancho virtual mayor y hace que la página se vea demasiado pequeña, rompiendo la experiencia responsive.

# Atributos globales en HTML

Hoy aprendí que existen ciertos atributos que se pueden aplicar prácticamente a cualquier elemento HTML, independientemente de su función. Estos atributos se conocen como **atributos globales** y permiten controlar aspectos como accesibilidad, estilo, comportamiento o identificación de los elementos.

Algunos de los atributos globales más utilizados son:

- **id**: identifica un elemento de forma única dentro del documento.
- **class**: asigna una o varias clases para aplicar estilos o seleccionar elementos desde JavaScript.
- **title**: muestra información adicional cuando se pasa el cursor por encima.
- **lang**: indica el idioma del contenido.
- **data-***: permite almacenar información personalizada sin afectar a la semántica.
- **hidden**: oculta un elemento sin eliminarlo del DOM.
- **tabindex**: controla el orden de navegación mediante teclado.

Conocer y utilizar correctamente estos atributos ayuda a crear documentos HTML más accesibles, mantenibles y fáciles de manipular.


# Uso de la etiqueta <link>

Hoy aprendí que la etiqueta `<link>` se utiliza para establecer relaciones entre el documento HTML y recursos externos que el navegador debe cargar o interpretar. Es una etiqueta vacía, por lo que no contiene contenido interno y se coloca normalmente dentro del `<head>`.

Los usos más comunes de la etiqueta `<link>` son:

- Cargar hojas de estilos CSS.
- Definir el favicon del sitio.
- Conectar archivos de manifiesto en aplicaciones web.
- Optimizar la carga de recursos mediante `preload`, `prefetch` o `preconnect`.

Ejemplo básico de uso:

```html
<link rel="stylesheet" href="styles.css">


# Uso correcto de la etiqueta <label>

Hoy repasé la importancia de utilizar correctamente la etiqueta <label> en formularios HTML, especialmente por motivos de accesibilidad y experiencia de usuario.

Un elemento <label> debe estar asociado a un control de formulario, normalmente mediante el atributo for. El valor de este atributo debe coincidir con el id del input correspondiente, lo que permite que al hacer clic sobre el texto del label, el input reciba el foco automáticamente.

Ejemplo de uso correcto:

<label for="email">Correo electrónico</label>
<input type="email" id="email">


También es válido envolver directamente el input dentro del propio <label>, en cuyo caso no es necesario usar el atributo for:

<label>
  Correo electrónico
  <input type="email">
</label>


Usar correctamente <label> mejora notablemente la accesibilidad, facilita la navegación mediante teclado y ayuda a los lectores de pantalla a interpretar correctamente los formularios.
