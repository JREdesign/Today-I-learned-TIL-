# HTML – Notas iniciales

Este archivo recoge varios conceptos y recordatorios básicos sobre HTML que he ido aprendiendo o repasando, organizados en secciones independientes para facilitar su consulta futura.

---

## Diferencia entre <section> y <article>

El elemento <section> se utiliza para agrupar contenido relacionado dentro de una página, mientras que <article> representa una unidad de contenido independiente que podría existir por sí misma, como una entrada de blog, un comentario o una tarjeta de producto.

---

## Para qué sirve el meta viewport

El meta viewport indica al navegador cómo debe adaptar el contenido al ancho real del dispositivo, siendo fundamental para un diseño responsive correcto.

Ejemplo habitual:

    <meta name="viewport" content="width=device-width, initial-scale=1">

---

## Atributos globales en HTML

Existen ciertos atributos que pueden aplicarse a prácticamente cualquier elemento HTML. Algunos de los más comunes son id, class, title, lang, data-*, hidden y tabindex. Estos atributos permiten controlar aspectos de accesibilidad, estilo y comportamiento.

---

## Uso correcto de la etiqueta <label>

La etiqueta <label> se utiliza para describir controles de formulario y debe estar correctamente asociada a su input correspondiente para mejorar la accesibilidad y la experiencia de usuario.

Ejemplo con atributo for:

    <label for="email">Correo electrónico</label>
    <input type="email" id="email">

También es válido envolver directamente el input dentro del propio label, sin usar el atributo for.

---

## Uso de la etiqueta <link>

La etiqueta <link> se utiliza para establecer relaciones entre el documento HTML y recursos externos como hojas de estilo, iconos o archivos de manifiesto, y suele colocarse dentro del elemento <head>.

Ejemplo básico:

    <link rel="stylesheet" href="styles.css">
