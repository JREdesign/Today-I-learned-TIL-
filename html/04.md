# HTML – &lt;noscript&gt;

El elemento &lt;noscript&gt; permite mostrar contenido alternativo cuando JavaScript está deshabilitado o no disponible.

Ejemplo:

    <noscript>
      Necesitas activar JavaScript para usar esta aplicación.
    </noscript>

Es útil para avisos básicos, fallback de contenido o mensajes en aplicaciones que dependen mucho de JavaScript.

# HTML – &lt;fieldset&gt; y &lt;legend&gt;

El elemento &lt;fieldset&gt; permite agrupar controles relacionados dentro de un formulario, mientras que &lt;legend&gt; proporciona un título para ese grupo.

Ejemplo:

    <fieldset>
      <legend>Preferencias de contacto</legend>
      <label>
      
        <input type="radio" name="contact" value="email" />
        Correo electrónico
      </label>

      <label>
        <input type="radio" name="contact" value="phone" />
        Teléfono
      </label>
    </fieldset>

Además de organizar visualmente el formulario, esta estructura aporta información útil a lectores de pantalla.

# HTML – &lt;datalist&gt;

El elemento &lt;datalist&gt; permite ofrecer sugerencias para un input sin obligar al usuario a seleccionar una de ellas.

El input se relaciona con la lista mediante el atributo list:

   < label for="browser">Navegador:< /label >
   
   < input id="browser" name="browser" list="browsers" />

    < datalist id="browsers">
      < option value="Chrome"></option>
      < option value="Firefox"></option>
       <option value="Safari"></option>
    < /datalist>

A diferencia de un &lt;select&gt;, el usuario puede escribir un valor que no aparezca en las opciones.

# HTML – &lt;progress&gt; y &lt;meter&gt;

Aunque pueden parecer similares, &lt;progress&gt; y &lt;meter&gt; representan conceptos diferentes.

&lt;progress&gt; muestra el avance de una tarea.:

    <label for="upload">Subida del archivo:</label>
    <progress id="upload" value="60" max="100">60%</progress>

&lt;meter&gt; representa un valor dentro de un rango conocido, como una puntuación, una batería o el uso de almacenamiento:

   <label for="storage">Almacenamiento usado:</label>
   < meter id="storage" value="70" min="0" max="100">70%< /meter >

La diferencia principal es que progress expresa progreso, mientras que meter muestra una medición.

# JavaScript – Array.find y Array.filter

find y filter recorren un array usando una condición, pero devuelven resultados diferentes.

find devuelve el primer elemento que cumple la condición:

    const users = [
      { id: 1, name: "Ana" },
      { id: 2, name: "Jorge" }
    ];

    users.find(user => user.id === 2);
    // { id: 2, name: "Jorge" }

filter devuelve un nuevo array con todos los elementos que cumplen la condición:

    const numbers = [1, 2, 3, 4];

    numbers.filter(number => number % 2 === 0);
    // [2, 4]

Si solo necesitas una coincidencia, find expresa mejor la intención y deja de recorrer cuando la encuentra.

# HTML – &lt;output&gt;

El elemento &lt;output&gt; representa el resultado de un cálculo o de una acción realizada por el usuario.

Ejemplo:

    <form oninput="result.value = Number(a.value) + Number(b.value)">
      <input id="a" type="number" value="0" />
      <input id="b" type="number" value="0" />
      <output name="result" for="a b">0</output>
    </form>

El atributo for puede indicar qué controles participan en el resultado.

Semánticamente, &lt;output&gt; es más apropiado que usar un elemento genérico cuando se muestra el resultado de una operación.
