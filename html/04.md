# HTML – &lt;noscript&gt;

El elemento &lt;noscript&gt; permite mostrar contenido alternativo cuando JavaScript está deshabilitado o no disponible.

Ejemplo:

    <noscript>
      Necesitas activar JavaScript para usar esta aplicación.
    </noscript>

Es útil para avisos básicos, fallback de contenido o mensajes en aplicaciones que dependen mucho de JavaScript.

# HTML – &lt;fieldset&gt; y &lt;legend&gt;

El elemento &lt;fieldset&gt; permite agrupar controles relacionados dentro de un formulario, mientras que &lt;legend&gt; proporciona un título para ese grupo.

Ejemplo:

    <fieldset>
      <legend>Preferencias de contacto</legend>
      <label>
      
        <input type="radio" name="contact" value="email" />
        Correo electrónico
      </label>

      <label>
        <input type="radio" name="contact" value="phone" />
        Teléfono
      </label>
    </fieldset>

Además de organizar visualmente el formulario, esta estructura aporta información útil a lectores de pantalla.

# HTML – &lt;datalist&gt;

El elemento &lt;datalist&gt; permite ofrecer sugerencias para un input sin obligar al usuario a seleccionar una de ellas.

El input se relaciona con la lista mediante el atributo list:

   < label for="browser">Navegador:< /label >
   
   < input id="browser" name="browser" list="browsers" />

    < datalist id="browsers">
      < option value="Chrome"></option>
      < option value="Firefox"></option>
       <option value="Safari"></option>
    < /datalist>
