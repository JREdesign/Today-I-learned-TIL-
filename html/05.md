# HTML – &lt;mark&gt;

El elemento &lt;mark&gt; representa texto destacado porque resulta relevante dentro del contexto actual.

Ejemplo:

    <p>
      Resultado encontrado para
      <mark>JavaScript</mark>.
    </p>
    
Un caso habitual es resaltar las palabras que coinciden con una búsqueda.

No debe utilizarse simplemente como sustituto de estilos visuales como un fondo amarillo; su uso tiene significado semántico.

Si solo quieres cambiar la apariencia de un texto sin indicar relevancia especial, es preferible utilizar CSS.
