# HTML – `<mark>`

El elemento HTML `<mark>` señala un fragmento de texto especialmente **relevante en el contexto actual**. Un caso habitual es destacar la palabra que coincide con una búsqueda.

## Ejemplo básico

```html
<p>
  Resultado encontrado para <mark>JavaScript</mark>.
</p>
```

El navegador suele mostrar el texto marcado con un fondo amarillo, aunque esa apariencia se puede personalizar con CSS.

## Cuándo utilizarlo

- Para destacar coincidencias en resultados de búsqueda.
- Para señalar un fragmento importante en un texto que estamos revisando o comentando.

**Importante:** `<mark>` aporta significado semántico; no debe utilizarse solo para pintar el fondo de un texto. Si únicamente queremos cambiar su apariencia, es preferible aplicar CSS.

## Diferencia con `<strong>` y `<em>`

- `<mark>` destaca la **relevancia contextual** de un fragmento.
- `<strong>` expresa especial **importancia, seriedad o urgencia**.
- `<em>` indica **énfasis** en una palabra o expresión.

Estos elementos no son intercambiables: conviene elegirlos según el significado que queremos transmitir.

## Personalizar el resaltado

```html
<p>Encontramos <mark class="resultado">tres coincidencias</mark>.</p>
```

```css
.resultado {
  background-color: #fff2a8;
  color: #242424;
}
```

Al modificar los colores, debemos mantener un contraste suficiente para que el texto resulte legible. Además, el color por sí solo puede no comunicar a todas las personas que existe un resaltado; cuando sea necesario, conviene proporcionar una pista adicional comprensible.
