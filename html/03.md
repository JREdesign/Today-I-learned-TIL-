# HTML – atributo download en enlaces

El atributo download en un enlace indica al navegador que, en lugar de navegar a la URL, intente descargar el recurso.

Ejemplo:

    <a href="/docs/guia.pdf" download>Descargar guía</a>

También puede sugerirse un nombre de archivo:

    <a href="/docs/guia.pdf" download="guia-front-end.pdf">Descargar guía</a>

Es útil para recursos estáticos como PDFs, imágenes o archivos generados para el usuario.

# HTML – spellcheck

El atributo spellcheck indica si el navegador debe comprobar la ortografía en campos editables.

Ejemplo:

    <textarea spellcheck="true"></textarea>

También puede desactivarse:

    <input type="text" spellcheck="false" />

Es útil cuando el contenido es código, identificadores o datos donde la autocorrección puede molestar más que ayudar.

# HTML – atributo `hidden`

El atributo global `hidden` en HTML se utiliza para indicar que un elemento no debe mostrarse ni considerarse relevante para el usuario en ese momento. Cuando un elemento tiene este atributo, el navegador normalmente lo oculta automáticamente de la interfaz visual.

## Sintaxis básica

```html
<p hidden>Mensaje oculto</p>
```

También puede escribirse así:

```html
<div hidden="hidden">Contenido oculto</div>
```

En HTML moderno no es obligatorio asignarle un valor; basta con incluir el atributo.

---

# ¿Qué ocurre cuando un elemento tiene `hidden`?

Cuando un elemento posee este atributo:

- El navegador deja de mostrarlo visualmente.
- El elemento no ocupa espacio en la página.
- El contenido sigue existiendo en el DOM.
- JavaScript puede acceder y modificar el elemento normalmente.
- HTML interpreta que el contenido no debería estar disponible actualmente.

Ejemplo:

```html
<section hidden>
    <h2>Configuración avanzada</h2>
    <p>Opciones adicionales del sistema.</p>
</section>
```

---

# Diferencia entre `hidden` y `display: none`

Aunque ambos métodos ocultan contenido, no significan exactamente lo mismo.

## Usando `hidden`

```html
<p hidden>Texto oculto</p>
```

Características:

- Tiene significado semántico.
- Indica que el contenido no debe mostrarse temporalmente.
- Expresa intención directamente desde HTML.

## Usando CSS

```html
<p style="display:none;">Texto oculto</p>
```

Características:

- Solo afecta a la presentación visual.
- No añade significado semántico.
- Se usa principalmente para estilos.

Muchos navegadores aplican internamente un comportamiento parecido a este:

```css
[hidden] {
    display: none;
}
```

# Manipulación con JavaScript

El atributo `hidden` es especialmente útil en interfaces dinámicas.

## Mostrar un elemento oculto

```html
<p id="mensaje" hidden>Hola</p>

<script>
document.getElementById("mensaje").hidden = false;
</script>
```

## Ocultar un elemento

```javascript
document.getElementById("mensaje").hidden = true;
```

## Añadir el atributo manualmente

```javascript
element.setAttribute("hidden", "");
```

## Eliminar el atributo

```javascript
element.removeAttribute("hidden");
```

# Casos de uso comunes

## Contenido desplegable

```html
<div id="info" hidden>
    Información adicional
</div>
```

## Menús dinámicos

```html
<nav hidden>
    Menú de navegación
</nav>
```

## Ventanas modales

```html
<div id="modal" hidden>
    Ventana emergente
</div>
```

## Interfaces interactivas

Muy usado en:

- Tabs
- Acordeones
- Formularios progresivos
- Paneles de configuración
- Componentes dinámicos

---

# Accesibilidad

El atributo `hidden` normalmente hace que el contenido deje de ser accesible también para tecnologías asistivas, como lectores de pantalla.

Por ello:

- Debe utilizarse únicamente cuando el contenido realmente no debe estar disponible.
- No es recomendable usarlo para ocultar contenido que todavía necesita ser leído por tecnologías de accesibilidad.

---

# Compatibilidad

El atributo `hidden` está soportado por todos los navegadores modernos:

- Google Chrome
- Firefox
- Safari
- Microsoft Edge
- Opera

---

# Resumen

El atributo `hidden`:

- Oculta elementos automáticamente.
- Tiene significado semántico.
- Mantiene el contenido en el DOM.
- Es ideal para interfaces dinámicas.
- Puede controlarse fácilmente con JavaScript.

Ejemplo final:

```html
<button onclick="mensaje.hidden = !mensaje.hidden">
    Mostrar / ocultar
</button>

<p id="mensaje" hidden>
    Este mensaje aparece y desaparece dinámicamente.
</p>
```
