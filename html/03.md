# HTML – atributo download en enlaces

El atributo download en un enlace indica al navegador que, en lugar de navegar a la URL, intente descargar el recurso.

Ejemplo:

    <a href="/docs/guia.pdf" download>Descargar guía</a>

También puede sugerirse un nombre de archivo:

    <a href="/docs/guia.pdf" download="guia-front-end.pdf">Descargar guía</a>

Es útil para recursos estáticos como PDFs, imágenes o archivos generados para el usuario.

# HTML – spellcheck

El atributo spellcheck indica si el navegador debe comprobar la ortografía en campos editables.

Ejemplo:

    <textarea spellcheck="true"></textarea>

También puede desactivarse:

    <input type="text" spellcheck="false" />

Es útil cuando el contenido es código, identificadores o datos donde la autocorrección puede molestar más que ayudar.

# HTML – atributo hidden 

El atributo hidden indica que un elemento no debe mostrarse al usuario. 

Ejemplo: <p hidden>Mensaje oculto</p> 

A diferencia de ocultar visualmente con estilos personalizados, hidden tiene significado semántico: el contenido no está pensado para estar disponible en ese momento. 

Es útil para contenido que se muestra dinámicamente con JavaScript.

# HTML – aria-current

aria-current indica cuál es el elemento actual dentro de un conjunto, por ejemplo en navegación o paginación.

Ejemplo:

    <a href="/blog" aria-current="page">Blog</a>

Esto ayuda a tecnologías de asistencia a comunicar mejor dónde se encuentra el usuario.

Valores comunes:

- page
- step
- location
- date
- true

# HTML – input type="search"

El tipo search está pensado para campos de búsqueda y puede ofrecer pequeños comportamientos nativos según el navegador, como un botón para limpiar el texto.

Ejemplo:

    <input type="search" name="q" placeholder="Buscar..." />

Semánticamente comunica mejor la intención del campo que un input de tipo text genérico.

---

# HTML – capture en input file

El atributo capture puede sugerir al dispositivo que use directamente cámara o micrófono al seleccionar un archivo, especialmente en móviles.


Valores comunes:

- user: cámara frontal
- environment: cámara trasera

No todos los navegadores lo tratan igual, así que conviene probarlo en dispositivos reales.

Ejemplo:

    <input type="file" accept="image/*" capture="environment" />

# HTML – enterkeyhint

enterkeyhint permite sugerir al teclado virtual qué texto o icono mostrar en la tecla Enter, especialmente en móviles.
